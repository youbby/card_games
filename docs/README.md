# Card Games — 기획/설계 문서

안드로이드에 설치해서 혼자 CPU와 대전하는 카드 게임 앱. 첫 게임은 **텍사스 홀덤**.
도박 목적이 아닌 **게임용 가상 칩**만 사용합니다.

## 한 줄 요약

> 실행 → 플레이할 캐릭터 선택(없으면 생성) → 로비에서 게임 선택 → 상대 클래스(Low/High)·인원(2~6) 선택 → CPU와 홀덤 → 칩과 전적은 캐릭터별로 영구 저장 → 파산한 캐릭터는 잠기고 새 캐릭터로 다시 시작.

## 확정된 요구사항

1. 안드로이드 설치형 앱, **GitHub Releases에서 APK 내려받아 설치** (GitHub 연동은 어느 정도 완성 후)
2. 1인 플레이어 vs CPU, CPU 클래스 **Low / High**
3. 첫 게임은 **텍사스 홀덤**, 이후 다른 카드 게임 추가 가능한 구조
4. **로그인 없음**, 기기 내 캐릭터로 사용자 구분 → 캐릭터별 칩 유지
5. 실행할 때마다 **플레이할 캐릭터 선택**
   - 캐릭터가 없으면 생성 화면으로
   - 모두 파산 상태면 새 캐릭터 생성 안내
6. **파산한 캐릭터는 플레이 불가**, 새 캐릭터로 진행
7. 캐릭터별 **전적 기록**
8. **CPU 풀**: Low 10명 + High 10명을 미리 생성. CPU도 칩을 유지하며, 파산하면 삭제되고 같은 클래스에 새 CPU가 생성되어 **클래스별 10명 유지**
9. 게임 시작: 게임 선택 → **클래스 선택** → **인원 선택(최대 6명, 나 포함)** → 시작
10. **블라인드 단계 선택**: 난이도별로 범위 분리 (하수: 입문~일반 / 고수: 중급~VIP), 잔액이 부족한 단계는 선택 불가
11. 설정에서 **시작 칩 변경** 가능 — 플레이어 캐릭터 생성 시에만 적용
12. **전체 초기화**: 앱을 설치 직후 상태로
13. 기술 스택: Capacitor + React + TypeScript (장단점은 [04-architecture.md](04-architecture.md#1-기술-스택과-장단점))
14. 기존 프로토타입은 **참고만** 하고 새로 개발
15. 코드 작성 시작부터 **로컬 git** 사용
