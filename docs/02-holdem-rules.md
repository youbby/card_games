# 02. 텍사스 홀덤 규칙 명세 (엔진 구현 기준)

No-Limit Texas Hold'em 캐시 게임, 2~6인. 엔진은 이 문서의 규칙을 그대로 구현하고, 각 항목은 단위 테스트로 검증한다.

## 1. 기본 진행

1. 딜러 버튼 이동 (활성 좌석 중 시계방향 다음)
2. 블라인드 포스팅: 버튼 왼쪽 = SB, 그 다음 = BB
3. 홀카드 2장씩 배분 (SB부터)
4. **프리플랍** 베팅: BB 다음 좌석(UTG)부터
5. **플랍** 3장 → 베팅 (버튼 왼쪽 첫 활성 좌석부터)
6. **턴** 1장 → 베팅
7. **리버** 1장 → 베팅
8. **쇼다운** 또는 1명만 남으면 즉시 종료

번 카드는 연출용으로만 처리(덱에서 1장 버림)해도 확률에 영향 없음 — 구현은 선택.

## 2. 헤즈업(2인) 특수 규칙
- **버튼이 SB**, 상대가 BB
- 프리플랍: **버튼(SB)이 먼저** 액션
- 플랍 이후: **BB가 먼저** 액션

2인으로 시작한 게임과, 인원이 줄어 2명이 된 게임 모두에 적용.

## 3. 베팅 규칙

### 액션 종류
`FOLD`, `CHECK`, `CALL`, `BET`, `RAISE`, `ALL_IN`

- 콜할 금액이 0이면 CHECK / BET 가능, 아니면 FOLD / CALL / RAISE
- 콜 금액 ≥ 스택이면 CALL은 곧 올인 콜 (Call 버튼으로 가능해야 함)

### 최소 베팅 / 최소 레이즈
- 최소 오픈 베팅 = BB
- 최소 레이즈 = **직전 베팅/레이즈 증가분** 이상
  - 예: BB 100, A가 300으로 레이즈(증가분 200) → B의 최소 레이즈 금액은 500
- 최대 = 스택 전부 (No-Limit)

### 불완전 올인 레이즈
- 최소 레이즈에 못 미치는 올인은 **베팅을 다시 열지 않음**
- 이미 액션한 플레이어는 그 올인에 대해 콜/폴드만 가능 (레이즈 불가)

### 베팅 라운드 종료 조건
- 폴드하지 않았고 올인도 아닌 플레이어 모두가 현재 최고 베팅과 같은 금액을 냈고
- 마지막 공격적 액션 이후 모두가 한 번씩 액션함
- 프리플랍 BB 옵션: 아무도 레이즈하지 않으면 BB에게 체크/레이즈 기회
- 액션 가능한 플레이어(올인 아닌)가 1명 이하이면 남은 보드를 자동으로 깔고 쇼다운 (런아웃)

## 4. 팟과 사이드팟

플레이어별 이번 핸드 **총 기여액**을 기록하고, 쇼다운 시 다음 알고리즘으로 팟을 나눈다.

```
contributions = 각 플레이어의 핸드 전체 기여액 (폴드한 사람 포함)
levels = 폴드 안 한 올인 플레이어의 기여액들 + 최대 기여액, 오름차순 고유값
prev = 0
for level in levels:
    pot.amount   = Σ ( min(c, level) - min(c, prev) )   (모든 플레이어 대상)
    pot.eligible = 폴드하지 않았고 기여액 >= level 인 플레이어
    prev = level
```

- 각 팟은 eligible 중 최고 족보가 가져감
- 무승부면 균등 분배, **나머지 칩(odd chip)** 은 버튼 왼쪽에서 가장 가까운 승자에게
- 아무도 콜하지 않은 초과 베팅은 해당 플레이어에게 반환 (uncalled bet)
- **불변식**: 핸드 전후 테이블 전체 칩 합계는 같아야 함 (테스트와 시뮬레이터에서 매 핸드 검사)

## 5. 족보와 비교

높은 순: 로열 플러시 > 스트레이트 플러시 > 포카드 > 풀하우스 > 플러시 > 스트레이트 > 트리플 > 투페어 > 원페어 > 하이카드

- 7장 중 최고 5장 조합
- A-2-3-4-5(휠) 스트레이트 허용, 이때 하이카드는 5
- 동일 족보는 키커 순서대로 비교
- 무늬로 우열을 가리지 않음
- 결과에 **사용된 5장**을 포함 (UI 강조용)
- 프리플랍 UI 설명: "포켓 페어", "수딧 커넥터" 등

## 6. 쇼다운 공개
- MVP에서는 쇼다운 참가자 전원 자동 공개 (머킹 생략)
- 공개 순서: 마지막 공격적 액션을 한 플레이어부터, 없으면 버튼 왼쪽부터 (연출 순서)

## 7. 테이블/좌석 처리
- 스택 0인 CPU: 핸드 종료 후 리바이 또는 퇴장 (01-product-spec.md §5)
- 빈자리에 새로 앉은 CPU: 다음 핸드부터 바로 참여 (데드 블라인드 생략)
- 핸드 도중 플레이어가 일어나기 → 즉시 폴드 처리 후 남은 스택 정산
- 앱이 핸드 도중 종료됨 → 다음 실행 시 그 핸드는 **폴드로 간주**, 이미 낸 칩은 잃음 (05-data-model.md)

## 8. 테스트해야 할 대표 시나리오
- 3인 올인, 스택 모두 다름 → 사이드팟 2개, 각각 다른 승자
- 메인팟 무승부 + 사이드팟 단독 승자
- odd chip 분배
- 헤즈업 블라인드/액션 순서, 3인 → 2인으로 줄어드는 전환
- 불완전 올인 레이즈 후 레이즈 불가
- BB 옵션
- 프리플랍 전원 폴드 → BB 승리, uncalled bet 반환
- 휠 스트레이트, 보드 플레이(무승부), 키커 비교
- 칩 총량 보존 (모든 시나리오 공통)
