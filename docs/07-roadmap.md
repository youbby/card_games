# 07. 로드맵

> **진행 현황 (2026-10-27)**: M0~M6 1차 구현 완료. v0.2.0에서 드로우·바카라·블랙잭과 게임별 방 수익 한도 추가. 앱 아이콘과 테이블 조작부 개선, 서명·검증 스크립트 사용. 남은 것: 실기기 테스트, 스플래시·튜토리얼·성능 점검.

각 마일스톤은 **완료 기준**을 만족해야 다음으로 넘어간다. 엔진(M1)을 UI보다 먼저 완성하는 것이 핵심 — 규칙이 정확해야 칩과 전적을 믿을 수 있다.

## M0. 프로젝트 셋업
- [ ] **로컬 git 저장소 초기화**, `.gitignore` (node_modules, 빌드 산출물, keystore 제외)
- [ ] Vite + React + TypeScript + Tailwind 프로젝트 생성
- [ ] Vitest, ESLint, Prettier 설정
- [ ] Capacitor 추가, `android/` 생성, applicationId 확정
- [ ] 빈 화면을 실제 안드로이드 기기에 설치 (디버그 APK)

**완료 기준**: 디버그 APK가 기기에서 실행되고 비행기 모드에서도 열린다.

## M1. 홀덤 엔진 (UI 없음)
- [ ] `core/`: 카드, 덱, 시드 RNG, 7장 족보 평가 (+사용된 5장)
- [ ] `holdem/engine`: 상태 머신, `legalActions`, `applyAction`, 이벤트 발행
- [ ] 블라인드, 버튼 이동, 헤즈업 규칙, 인원 변동 처리
- [ ] 최소 레이즈, 불완전 올인, BB 옵션, 런아웃
- [ ] 사이드팟, odd chip, uncalled bet 반환
- [ ] 02-holdem-rules §8 시나리오 테스트
- [ ] 랜덤 봇 헤드리스 시뮬레이터 (`tools/simulate.ts`)

**완료 기준**: 랜덤 봇 2~6인 각 10만 핸드에서 칩 총량 보존, 예외·무한 루프 0건, 규칙 테스트 전부 통과.

## M2. 테이블 UI + Low 봇
- [ ] 테이블 화면 컴포넌트 (Table, Seat, Card, ActionBar, Pot, HandLog)
- [ ] 2~6인 좌석 자동 배치 (세로 화면)
- [ ] 엔진 이벤트 기반 애니메이션 (딜, 칩 이동, 카드 공개)
- [ ] 베팅 프리셋 (½팟, ¾팟, 팟), 사이드팟 표시, 이긴 5장 강조
- [ ] Low 봇

**완료 기준**: 기기에서 Low 봇 5명과 끊김·멈춤 없이 연속 플레이.

## M3. 캐릭터 & 저장 & CPU 풀
- [ ] Dexie 스키마, Repository 계층
- [ ] 실행 흐름: 캐릭터 0명 → 생성 / 모두 파산 → 안내 → 생성 / 그 외 → 선택
- [ ] 캐릭터 생성·선택·삭제 화면
- [ ] CPU 풀 생성 (Low 10 / High 10, 시작 칩 Low 10,000 / High 50,000), 이름·성향 생성
- [ ] 지갑 ↔ 테이블 바이인/캐시아웃 (플레이어·CPU, 트랜잭션)
- [ ] 핸드 종료 시 기록 저장 + 통계 갱신
- [ ] 비정상 종료 복구 (진행 중 핸드 = 플레이어 폴드)
- [ ] 파산: 플레이어 잠금 / CPU 삭제 + 보충 (CPU는 클래스별 기준)
- [ ] 설정: 시작 칩 (플레이어 캐릭터 생성 시에만 적용)
- [ ] **전체 초기화**

**완료 기준**: 강제 종료·재시작 후에도 잔액·전적이 정확하고, 파산한 캐릭터는 플레이 불가, CPU는 클래스별 항상 10명. 전체 초기화 후 첫 실행 상태로 돌아간다.

## M4. 로비 & 게임 설정 흐름
- [ ] 로비: 내 캐릭터 카드, 게임 목록, CPU 목록, 설정, 캐릭터 변경
- [ ] 게임 설정 단계: 클래스 → 인원(2~6) → 블라인드 → 바이인 → 상대 확인(다시 뽑기)
- [ ] 블라인드 선택 제한: 클래스별 허용 범위, 내 잔액, 참가 가능 CPU 수 → 잠금 사유 표시
- [ ] 테이블 중 CPU 리바이/퇴장/빈자리 보충 (선택한 인원 유지)
- [ ] 안드로이드 뒤로가기 처리

**완료 기준**: 캐릭터 선택 → 로비 → 클래스·인원 선택 → 플레이 → 일어나기 → 다른 설정으로 재시작 전체 흐름이 자연스럽다.
